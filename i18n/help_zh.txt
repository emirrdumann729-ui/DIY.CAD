鼠标
  中键拖动 .................... 旋转
  右键拖动 .................... 旋转（或鼠标笔势，见"选项"）
  Ctrl + 中键/右键 ............ 平移
  Shift + 中键 ................ 缩放
  滚轮 ........................ 向光标处缩放
  左键单击 .................... 选择   （双击：编辑）

键盘（可自定义：工具 → 选项 → 键盘快捷键）
  F ........................... 整屏显示全图
  Ctrl+1..7 ................... 前视、后视、左视、右视、上视、下视、等轴测
  Ctrl+8 ...................... 正视于
  方向键 ...................... 将视图旋转 15°
  Ctrl+Z / Ctrl+Y ............. 撤销 / 重做
  Ctrl+S / Ctrl+O / Ctrl+N .... 保存 / 打开 / 新建
  Ctrl+E ...................... 导出（所有格式）
  Delete ...................... 删除      F2：重命名
  Esc ......................... 取消 / 退出工具
  Enter ....................... 在特征面板中确定

草图模式
  L 直线   N 中心线   R 矩形   C 圆   A 圆弧
  D 智能尺寸   S 选择   G 网格捕捉
  P 多边形   T 剪裁   E 延伸
  在尺寸框中输入 =表达式 以链接方程式（例如 =width/2）
  双击 / 右键单击：结束直线链
  双击尺寸标签：更改其数值
  Shift/Ctrl + 单击：多选 → 从面板添加几何关系
  蓝色 = 欠定义，黑色 = 完全定义，红色 = 过定义

装配体（文件 → 新建装配体 / .dasm）
  插入零部件：零件文件；第一个零部件固定 (f)，欠定义 (-)
  左键拖动：在遵守配合的前提下移动零部件
  配合：单击面/边线 → 选择类型（★ 推荐）
  双击零部件（树）：编辑零件；"装配体"选项卡：返回
  新建零件：装配体中的零件（其他零部件半透明显示，可在其面上绘制草图）
  零部件阵列、子装配体（插入 .dasm）、"工程图"选项卡：装配体工程图
  大型装配体：自动 LOD；大型装配体模式只在所选对象上显示边线

钣金 / 焊件 / 曲面 / 分析（选项卡）
  基体法兰：闭合轮廓 → 平板，开环直线链 → 折弯钣金
  边线法兰 / 褶边：单击基体边线；展开、带折弯线的展开 DXF
  结构构件：沿草图 / 3D 草图直线的轮廓；切割清单 (CSV)
  评估 → 配置：尺寸 / 压缩组合，设计表 (CSV)
  曲面：拉伸 / 旋转 / 放样 / 平面区域，缝合，加厚，剪裁
  分析：静态有限元（单击固定面和载荷面）、拔模分析、CAM G 代码、可视化

选项、宏和插件（工具菜单）
  选项：语言、主题、界面缩放、自动保存、备份
  键盘快捷键：双击命令，按下按键（任何命令都可分配）
  鼠标笔势：按住右键并朝某方向拖动 → 命令环
  运行宏 / 开始-停止录制宏 / 将零件另存为宏
  插件：plugins/ 文件夹，"插件"选项卡；在"选项"中启用 / 禁用
  文件 → 最近的文件；崩溃后启动时恢复文档

工程图（选项卡）
  首次进入时自动创建带标准三视图和等轴测视图的 A3 图纸
  左键单击：选择 / 放置   拖动：移动视图或注解
  滚轮：缩放   右键/中键：平移   F：适合图纸
  Delete：删除所选视图/注解   Esc：释放工具 / 清除选择
  导出 (Ctrl+E)：PDF、DXF、SVG、AI、图像（用 AutoCAD / ODA 将 DXF 转换为 DWG）
