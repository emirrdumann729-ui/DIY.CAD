МЫШЬ
  Перетаскивание средней кнопкой ... вращение
  Перетаскивание правой кнопкой .... вращение (или жесты мыши, см. Параметры)
  Ctrl + средняя/правая кнопка ..... панорамирование
  Shift + средняя кнопка ........... масштаб
  Колесо ........................... масштаб к курсору
  Левый щелчок ..................... выбор   (двойной щелчок: редактирование)

КЛАВИАТУРА (настраивается: Инструменты → Параметры → Сочетания клавиш)
  F ................................ показать все
  Ctrl+1..7 ........................ Спереди, Сзади, Слева, Справа, Сверху, Снизу, Изометрия
  Ctrl+8 ........................... перпендикулярно
  Стрелки .......................... повернуть вид на 15°
  Ctrl+Z / Ctrl+Y .................. отменить / повторить
  Ctrl+S / Ctrl+O / Ctrl+N ......... сохранить / открыть / создать
  Ctrl+E ........................... Экспорт (все форматы)
  Delete ........................... удалить      F2: переименовать
  Esc .............................. отмена / выход из инструмента
  Enter ............................ OK на панели элемента

РЕЖИМ ЭСКИЗА
  L линия   N осевая линия   R прямоугольник   C окружность   A дуга
  D автоматический размер   S выбор   G привязка к сетке
  P многоугольник   T обрезка   E удлинение
  Введите =выражение в поле размера, чтобы связать уравнение (например, =width/2)
  Двойной щелчок / правый щелчок: завершить цепочку линий
  Двойной щелчок по размеру: изменить значение
  Shift/Ctrl + щелчок: множественный выбор → добавить взаимосвязь на панели
  Синий = недоопределен, черный = полностью определен, красный = переопределен

СБОРКА (Файл → Новая сборка / .dasm)
  Вставить компонент: файл детали; первый компонент зафиксирован (f), недоопределен (-)
  Перетаскивание левой кнопкой: перемещение компонента с учетом сопряжений
  Сопряжение: щелкните грани/ребра → выберите тип (★ предлагается)
  Двойной щелчок по компоненту (дерево): редактировать деталь; вкладка «Сборка»: вернуться
  Новая деталь: деталь внутри сборки (другие компоненты полупрозрачны, эскиз на их гранях)
  Массив компонентов, подсборка (вставка .dasm), вкладка «Чертеж»: сборочный чертеж
  Большие сборки: автоматический LOD; режим большой сборки показывает ребра только у выбранного

ЛИСТОВОЙ МЕТАЛЛ / СВАРНЫЕ КОНСТРУКЦИИ / ПОВЕРХНОСТИ / АНАЛИЗ (вкладки)
  Базовая кромка: замкнутый профиль → пластина, открытая цепочка линий → гнутый лист
  Ребро-кромка / подгиб: щелкните базовые ребра; развертка, DXF развертки с линиями сгиба
  Элемент конструкции: профиль по линиям эскиза / 3D-эскиза; список вырезов (CSV)
  Оценка → Конфигурация: наборы размеров / подавления, таблица параметров (CSV)
  Поверхности: вытянутая / повернутая / по сечениям / плоская поверхность, сшивка, толщина, обрезка
  Анализ: статический МКЭ (щелкните закрепленные грани и грани нагрузки), анализ уклонов, G-код CAM, визуализация

ПАРАМЕТРЫ, МАКРОСЫ И ПЛАГИНЫ (меню Инструменты)
  Параметры: язык, тема, масштаб интерфейса, автосохранение, резервная копия
  Сочетания клавиш: дважды щелкните команду, нажмите клавишу (назначить можно любой команде)
  Жесты мыши: удерживайте правую кнопку + потяните в сторону → кольцо команд
  Выполнить макрос / начать-остановить запись макроса / сохранить деталь как макрос
  Плагины: папка plugins/, вкладка «Плагины»; включение / отключение в Параметрах
  Файл → Последние файлы; восстановление документа при запуске после сбоя

ЧЕРТЕЖ (вкладка)
  При первом входе создается лист A3 со стандартными 3 видами и изометрией
  Левый щелчок: выбрать / разместить   Перетаскивание: переместить вид или примечание
  Колесо: масштаб   Правая/средняя кнопка: панорамирование   F: вписать лист
  Delete: удалить выбранный вид/примечание   Esc: отпустить инструмент / снять выбор
  Экспорт (Ctrl+E): PDF, DXF, SVG, AI, изображения (DXF в DWG — через AutoCAD / ODA)
